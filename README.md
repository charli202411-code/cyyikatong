# 重邮一卡通 · 校园生活

重庆邮电大学校园一卡通交互原型的在线演示版：面向学生的消费管理与校园生活应用，纯静态单文件实现，开箱即用。

> 说明：本站为**交互演示原型**，所有账户、余额与交易均为模拟数据，仅保存在访问者自己的浏览器中，不连接真实支付、学籍或学校系统。

## 在线体验

部署到 GitHub Pages 后，访问：

```
https://charli202411-code.github.io/cyyikatong/
```

## 本地运行

无需安装任何依赖，下载本仓库后双击 `index.html` 即可在浏览器中打开。

## 功能总览

| 模块 | 功能 |
|------|------|
| 首页 | 校园卡余额、付款码 / 扫一扫、宿舍用电与用水服务入口、待办事项 |
| 消费管理 | 自选日期区间账单（自然月 / 15日账期）、分类占比、手动补录现金与微信支出、账单导出 |
| 预算管理 | 月度预算、85% 阈值提醒（每日最多一次）、每日限额与单笔限额付款前校验 |
| 月底预测 | 按近 7 天消费节奏推算月底总支出、缺口来源分析、"每天少花 X 元"试算对比 |
| 宿舍生活 | 宿舍用电管家、室友电费 AA（发起人 / 舍友双方视角）、用水异常申报与退款闭环 |
| 校园卡 | 挂失与解挂、补卡进度、充值到账追踪、转账、补助与退款 |
| 个人 | 多账号注册登录、示例数据 / 空白账户两种模式、消费分析授权、提醒频率、账单周期设置 |

## 技术说明

- 单文件 HTML + CSS + 原生 JavaScript，无构建、无后端、无外部依赖，可离线运行
- 数据存储于浏览器 localStorage，按账号隔离，清除浏览器数据即可重置
- 适配移动端视口与安全区，支持键盘焦点管理与读屏语义
